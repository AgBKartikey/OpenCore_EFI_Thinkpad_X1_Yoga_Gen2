# Lenovo Thinkpad X1 Yoga Gen 2


Configured EFI for Lenovo Thinkpad X1 Yoga Gen 2 using [OpCore-Simplify](https://github.com/lzhoang2801/OpCore-Simplify), Tested with <b>Ventura 13.7.8</b>


# My Verdict?
- Performance is unexpectedly good for a general user with good multitasking as well
- No unusual lags, no random reboots
- Nothing that might stop you from installing MacOS on this device


# Device Specs? 
- <b>CPU</b>: Intel(R) Core(TM) i7-7600U CPU @ 2.80GHz (2.90 GHz) (Kaby Lake)
- <b>GPU</b>: Intel(R) HD Graphics 620 (128 MB)
- <b>Storage</b>: 512GB SSD
- <b>RAM</b>: 16 GB LPDDR3 1867MHz

# What's Working?
- Keyboard with All the Hotkeys, Brightness/Volume Buttons 
- Touchpad, work with all gestures
- Wifi / Bluetooth
- Speaker / Mic
- Camera
- Within MacOS, Map PrtSc Key to take Screenshot & Remap Windows&Alt Keys to have exactly same layout as macbook

# What's Not Working?
- Type-C Hotplug (Thunderbolt Limitation)
- 3.5mm Headphone Audio Jack (Tested Layout IDs 47,72,11,21 But Couldnt make it work, If you have time try 28,13,22

# Not Tested?
- Touch Screen & Pen (Display Physically Cracked 😓)
- HDMI (No device to test)
- Fingerprint (Ofc Wont Work)

- Disable Secureboot
